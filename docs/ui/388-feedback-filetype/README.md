# #388 反馈弹窗：非图片文件不再被静默当成截图

关单证据。**不是真机截图**：Playwright Chromium（headless）浏览器视口，
`deviceScaleFactor=2` + `isMobile` + `hasTouch` + `locale=zh-CN`，390×844 与 360×740 两档。
复现脚本：[`probe-388.mjs`](probe-388.mjs)（一次性探针，参数 `<dist 目录> <截图输出目录>`）。

## 结论

| 选的文件 | 改前（`dist-before`，= main 的 src） | 改后 |
| --- | --- | --- |
| `note.txt`（`text/plain`） | **没有任何提示**，预览区出现一个坏图（`alt` 破图占位），「移除」按钮出现 —— 点提交就把这个垃圾附件带上去 | 提示「只能附图片截图：请选择 png / jpg / webp 这类图片文件」，**没有预览**、没有「移除」 |
| `fake.png`（`image/png`，内容其实是文本） | 同上：静默收下 + 坏预览 | 提示「这张图片打不开（可能已损坏或不是真的图片），请换一张再试」，**没有预览** |

两档视口（390 / 360）结论一致；探针打印的原始输出：

```
# 改前（dist-before）
390 txt:      提示=[] 预览数=1
360 txt:      提示=[] 预览数=1
390 fake-png: 提示=[] 预览数=1
360 fake-png: 提示=[] 预览数=1

# 改后（dist，本分支）
390 txt:      提示=["只能附图片截图：请选择 png / jpg / webp 这类图片文件"] 预览数=0
360 txt:      提示=["只能附图片截图：请选择 png / jpg / webp 这类图片文件"] 预览数=0
390 fake-png: 提示=["这张图片打不开（可能已损坏或不是真的图片），请换一张再试"] 预览数=0
360 fake-png: 提示=["这张图片打不开（可能已损坏或不是真的图片），请换一张再试"] 预览数=0
```

改前的 `390-fake-png.png` 与 `390-txt.png` **逐字节相同**（`sha256 ba095f29…`），
按 `docs/ui/README.md` 的「同字节不同场景」口径本来该留、但这里两者代表的是**同一个观察**
（改前两种文件的表现完全一样：都是静默收下 + 坏预览），所以只留一份，特此登记。

## 未测边界

- 真机 / Android WebView 的相册选择器：未测。`accept="image/*"` 在部分系统选择器上仍能选到非图片
  文件（这正是本单的复现路径），但真机上的选择器行为没有实测。
- HEIC / AVIF：`looksLikeImage()` 认这些 MIME，但**能不能解码取决于内核**；解不开会走
  「这张图片打不开」那条提示，不会静默收下。
