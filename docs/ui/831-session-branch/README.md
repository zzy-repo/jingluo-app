# #831 会话级分支（session branch）· UI 取证

任务：从历史会话**分叉出独立的新会话**（完整分支 / 节点分支）。本目录是 390 / 360 两档浏览器视口截图，
由 `scripts/shot-mobile.mjs` 的 `--page=831-session-branch` 场景生成（**不是真机截图**）。

```bash
NODE_OPTIONS=--max-old-space-size=1536 node scripts/shot-mobile.mjs --page=831-session-branch --viewport=390,360
```

每条截图旁边有 `metrics.json`（两档各一份）：横向溢出、徽标两态文案、确认文案、默认命名、
创建后的标题 / 徽标状态、点徽标跳回后的标题都在里面 —— 「看着对」不算数，量到的数在盘上。

## 这一轮**没有**截到的（别把上面的图当全部证据）

- **附件降级「附件不可用」**：需要一条「原件真不在本机」的分支会话，截图 fixture 里没造（造它要把
  附件记录 / 原件都清掉，`seedInPage` 只写会话与摘要）。这条由
  `tests/unit/session-branch-831.test.mjs` 的 ⑤ 覆盖（真库：`attachments` 只 1 条、原件只 1 份、
  父会话删除后原件仍在、原件丢失后 `unavailableAttachmentIds()` 返回缺失且**不抛错**，另有 markup 断言
  「附件不可用」文案）。
- **桌面端（> 768px）布局**：本单只按仓库口径出 390 / 360 两档；桌面标题栏的徽标位置靠
  `SessionView.module.css` 的 `margin`，没有单独量过宽度。
- **长按菜单**：会话列表项的入口在「更多」（`⋯`）菜单里（移动端常显），本 App 没有实现长按手势，
  与既有「置顶 / 重命名 / 删除」同一条入口。
