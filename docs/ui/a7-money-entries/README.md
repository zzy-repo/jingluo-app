## 怎么重新生成

```bash
# 1. 标准产物（带测试接缝：未登录冷启动只会画登录页，截不到设置页）
TEST_AUTH_SEAM=1 pnpm build          # → dist/（接缝只改启动判定，不改本页 UI）
# 2. 起本地服务并截两档（脚本见仓库外的取证脚本；步骤等价于下面的 Playwright 操作）
#    - 预置 localStorage：provider-kind=ours（这格只在自有渠道出现，#166）、一个假 API Key
#    - 打开侧栏 → 设置 → 数据管理 → 把 [data-testid="account-consume-open"] 滚进视口 → 截图
#    - 同时量：上面那张表里的六项，写进 metrics.json
```

## 边界（别当成真机取证）

- **浏览器视口截图**，不是真机截图（`docs/ISSUE-STANDARD.md` 的口径：真机取证另走 adb）。
- 截图用的是 `TEST_AUTH_SEAM=1` 的产物：登录墙之后的界面在浏览器里没有真账号可登，
  接缝只把「启动判定」置成已登录（见 `docs/TESTING-POLICY.md` 第 13 节），
  设置页及其中的入口/文案与发版产物逐字相同。
- 图里 API Key 是假串 `sk-a7-acceptance-fixture`，不涉及任何真实凭据。
