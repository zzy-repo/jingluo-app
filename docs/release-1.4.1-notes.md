# 鲸落 1.4.1

本次是正式版（1.4.1，versionCode 20），直接覆盖安装即可。

一句话：**官方渠道「每条消息都报未知错误 / 说模型不可用」的问题修掉了，购买改成在 App 内直接打开收款页，检查更新和出错时的提示都能看懂到底出了什么事。**

## 本版修复

### 官方渠道（DeepSeek 官方 API）

- **修掉「每条消息都提示回答没有完成，出现了未知错误」**：发给上游的上下文快照少了一段，导致每一条请求都被拒绝。现在固定补齐，历史会话里已存下的旧快照在发出前也会自动补齐。
- **修掉「当前模型在上游不可用」（400：The supported API model names are …）**：不再沿用旧版本残留的模型名，升级后首次启动会做一次性配置迁移，把残留的旧配置清干净；之后模型名再出问题，错误提示里会带上实际发出的模型名，方便反馈。
- **出错时不再只说「未知错误」**：现在能区分内容拦截、模型不可用、参数错误、上游没返回内容、网络与超时，并给一句中文说明。内容拦截与参数错误会明确写「不要重试」，其它情况写「可以重试」。
- **Key 失效立即停止重试**：遇到 401（Key 无效 / 已过期）不再反复自动重试，设置页与聊天界面直接提示重新登录或重新填写 Key。
- **额度用完不再误报成「请求过于频繁」**：额度不足单独成一类，直接告诉你是额度问题，并给出去哪里充值。

### 购买与额度

- **购买入口改为在 App 内打开收款页**：点「前往购买」直接在 App 内弹出联动小铺收款页，关掉后自动刷新额度。不再整页跳转，也不再弹系统浏览器。
- **去掉旧的下单与查单轮询链路**（旧接口已停用）：购买区不再显示已下线的套餐卡片，改成「前往购买」按钮与一句说明。
- **附件上传修复**：不再请求服务端不存在的地址；不支持上传文件的渠道会明确显示为不可用，而不是点了没反应。
- **不再对 4xx 失败反复重试**：只有限流、服务端异常、超时与断网才会自动重试。

### 更新

- **检查更新失败时能看到原因**：断网、更新服务异常、更新清单数据异常、下载校验不通过会分开展示，并可以一键复制诊断信息，不用再只看到「请稍后重试」。
- **单个字段异常不再让整份更新清单失效**：遇到不认识的取值会退回默认判断，其余版本照常可用。
- **升级源切到新的分发服务器**，旧服务器保留为回退，某一台不可用不会直接让更新失败。

### 聊天与界面

- **等待回复时会显示进展**：显示当前进行到哪一步、已经等了多少秒，长回答不再看起来像卡死。
- **「深度思考 / 专家模式」入口统一**：四个渠道的入口都常驻可点，点了会记住你的选择；确实不支持的渠道不会偷偷多发请求。
- **兜底页可自助报障**：启动失败时的提示页会显示 App 版本、系统内核版本、Android 版本、失败阶段与时间，并可一键复制。
- **图标换成鲸鱼图**，自适应图标去掉白边。
- **旧机型显示问题批量修复**：滚动条抖动导致的横向跳动、flex 间距丢失、焦点样式丢失、对话背景文字竖排、设置页文字挤压，以及 emoji 与组合字符被切碎。
- **导入更稳**：超过大小上限在下载前就拒绝；失败提示能分清是离线还是地址不可用；系统时间跳变不再让耗时统计出错。
- **邀请积分显示修复**（被邀请人不再看到「获得 0 积分」）。
- **支付记录展示订单与卡密的完整时间线**。

## 升级方式

- **直接覆盖安装，不需要卸载**。覆盖安装不会丢数据：聊天记录、设置、已填写的 Key、额度与卡密都保留在原处。
- 已在用 1.4.0 的用户会在检查更新时收到本版提示；本版 versionCode 20 高于 1.4.0 的 19，可正常覆盖升级。
- 如果覆盖安装被系统拒绝，说明手机里装的是不同签名的安装包（例如从别的渠道装的），只能卸载重装 —— 这种情况请先导出/备份重要会话。

## 注意：覆盖安装不会丢数据

- 聊天记录保存在 App 本地，覆盖安装不清数据。
- 额度与卡密绑定的是本机设备码，覆盖安装不会改变设备码，无需重新领取。
- 仍然建议定期备份：设备码丢失等于丢账号，请在「额度与卡密」里复制并保存好设备码。

## 遇到问题

应用内「反馈」入口可以直接提交，附带诊断信息（不含 Key、不含聊天正文）；启动失败时用兜底页的「复制信息」把版本与内核信息一并发给我们，排查会快很多。
